# 天寻AI原创笔记图工作台复刻版

这是一个基于你提供的截图风格复刻的前端原型，包含多工具页、顶部导航、工具卡片、上传图片区域、参数滑块、笔记预览、生成弹窗和服务配置弹窗。

## 运行方式

直接打开：

```bash
index.html
```

或启动本地服务：

```bash
npx serve
```

## 功能范围

- 复刻页面结构与视觉风格
- 支持页面间切换
- 支持图片上传区域展示
- 支持弹窗交互
- 支持笔记预览更新
- 后端 API、账号、真实 AI 生成暂未接入

## 目录

- `index.html`：页面结构与样式
- `app.js`：交互逻辑
- `assets/`：预留静态资源目录
